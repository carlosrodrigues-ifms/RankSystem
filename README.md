# 🏆 RankSystem

Sistema de ranking automático desenvolvido para a disciplina de Prática Profissional.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📌 Funcionalidades

- Adicionar participantes
- Editar pontuações
- Excluir participantes
- Ordenar o ranking
- Pesquisar participantes
- Exibir estatísticas
- Mostrar o pódio
